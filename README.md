# Social Media App (Backend)

Backend system for a social media platform built with Node.js, Express, and MongoDB. Supports JWT authentication, user profiles, posts, comments, likes, and follow/unfollow system.

## Features
- User authentication with JWT
- User profiles and account management
- Posts, comments, and likes
- Follow/Unfollow system
- RESTful API endpoints

## Tech Stack
- Node.js
- NestJS
- MongoDB
- Mongoose
- JWT
- REST API

## Installation
1. Clone the repo
2. Run `npm install`
3. Run `npm run start:dev`
